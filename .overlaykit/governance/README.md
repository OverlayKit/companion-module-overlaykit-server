# OverlayKit Companion Governance

This directory is a contract, not a mutable notebook.

- `decisions/` contains immutable ADR records.
- `specifications/` contains accepted capabilities and observable workflows.
- `changes/` contains typed Slice contracts.
- `profile.json` selects the law currently in force.
- `mechanisms.json` identifies concrete enforcement mechanisms.
- `plan.json` and `manifest.json` are generated artifacts.

Evidence is stored separately and is current only when its profile, plan, manifest, repository,
commit, ref, event, and producer match the compiled contract.

Memory Cloud preserves lessons and operational context. It is not normative law.
