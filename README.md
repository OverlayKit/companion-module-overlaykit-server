# OverlayKit Companion Module

This repository will contain the governed Bitfocus Companion module for controlling an
[OverlayKit](https://github.com/OverlayKit/overlaykit) production from Linux.

The repository is currently in its constitutional bootstrap. No adapter behavior is claimed until
the approved H-031 experiment has produced reviewable evidence.

## Development Status

- Governance and legal provenance: bootstrapping
- Companion adapter: not yet implemented
- npm publication: not established
- Bitfocus module registry: not established
- Physical Stream Deck hardware: not tested

## Governance

The compiled contract under `.overlaykit/governance/` is normative. Read [AGENTS.md](AGENTS.md)
before changing the repository.
